# Game Design Document (szkic)

Autor: Mateusz Bartoszewicz

Status: szkic. Pola oznaczone **DO USTALENIA** wymagają decyzji i nie wolno ich uzupełniać domysłami. Źródło ustaleń: `CLAUDE.md` (sekcje 1, 2 i 12).

## 1. Ustalone

- Gra 2D top-down w stylu Stardew Valley, ale oryginalna (nie klon).
- Spokojna pętla: dzień → praca → zysk → rozwój.
- Pixel art.
- Silnik: Godot. Start w 2D, w przyszłości możliwe 3D.
